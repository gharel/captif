# Formes complémentaires

Plan : tester les primitives et la reprise JSON, étendre le catalogue de modèles, puis laisser la palette et le rendu intégrer leurs noms/icônes dans le chantier parent.

Ajouts : nœud de déploiement, port, interfaces fournie/requise, points d'entrée/sortie, terminaison, jonction, signaux émission/réception, événement temporel, objet de données, processus/sous-processus, entrée-sortie, document, saisie manuelle, préparation, entité faible et relation identifiante.

Chaque élément est un groupe de primitives existantes, borné à la zone A4. Le champ de nom est vide quand `name: ''` est fourni ; aucune donnée ni exemple n'est ajouté. Les marqueurs compacts sans nom ne contiennent pas de faux texte. Les modèles sont éditables, sauvegardables et imprimables ; les identifiants sont stables lors d'une modification. Cette extension ne prétend pas reproduire exhaustivement les bibliothèques Miro.
